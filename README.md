# Свадебный сайт Максима и Оли

Одностраничное приглашение на 1 ноября 2026 года. Проект сделан на HTML, CSS и
обычном JavaScript; Vite используется только как локальный сервер и сборщик.

## Запуск

```bash
npm install
npm run dev
```

В локальном режиме анкета не отправляет данные наружу: последний ответ сохраняется
в `localStorage` браузера. Производственная сборка создаётся командой:

```bash
npm run build
```

## Изменение оформления и контента

- Цвета и шрифты: верхний блок переменных в `src/styles/main.css`.
- Дата таймера: `src/config.js`.
- Тексты, ссылки и контакты: `index.html`.
- Исходные фотографии: `source-images/`.
- Оптимизированные фотографии: `public/images/`.

## Подключение анкеты

1. Создать Google Form с обязательными вопросами «Имена», «Количество гостей» и
   «Сможете присутствовать?». Варианты третьего вопроса: «Да, буду» и
   «К сожалению, не смогу».
2. Связать ответы формы с Google-таблицей и опубликовать форму с доступом по
   ссылке.
3. В Vercel добавить `GOOGLE_FORM_ACTION_URL`, `GOOGLE_FORM_NAMES_FIELD`,
   `GOOGLE_FORM_GUEST_COUNT_FIELD` и `GOOGLE_FORM_ATTENDANCE_FIELD` из
   `.env.local`.

Фронтенд отправляет данные только в `/api/rsvp`. Серверная функция проверяет
имена, количество гостей, вариант ответа, защитное поле и время заполнения,
после чего передаёт ответ в Google Form.

## Размещение

Репозиторий подключается к Vercel. Платформа автоматически выполнит `npm run build`
и опубликует папку `dist`. До подключения собственного адреса сайт работает на
выданном Vercel домене `*.vercel.app`.
