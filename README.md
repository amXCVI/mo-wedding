# Свадебный сайт Максима и Оли

Одностраничное приглашение на 1 ноября 2026 года. Проект сделан на HTML, CSS и
обычном JavaScript; Vite используется только как локальный сервер и сборщик.

## Запуск

```bash
npm install
npm run dev
```

В локальном режиме анкета не отправляет данные наружу: последний ответ сохраняется
в `localStorage` браузера. Производственная сборка создаётся командой:

```bash
npm run build
```

## Изменение оформления и контента

- Цвета и шрифты: верхний блок переменных в `src/styles/main.css`.
- Дата таймера: `src/config.js`.
- Тексты, ссылки и контакты: `index.html`.
- Исходные фотографии: `source-images/`.
- Оптимизированные фотографии: `public/images/`.

## Анкета

Фронтенд отправляет ответы прямо в опубликованную Google Form. Адрес формы и
идентификаторы вопросов находятся в `src/rsvp-config.js`.

## Размещение

Сайт публикуется на GitHub Pages workflow-файлом
`.github/workflows/deploy-pages.yml`. При каждом push в `main` GitHub Actions
выполняет `npm ci`, собирает проект и публикует папку `dist`.
